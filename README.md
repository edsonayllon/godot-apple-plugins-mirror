# Godot Apple Plugins mirror

A copy of the [Godot Apple Plugins](https://github.com/migueldeicaza/GodotApplePlugins) addon build that
Poker Ranked's iOS build depends on. The upstream release (`build-a66f619a253cbc39922ff9018b2307b6ec6862cc`, the one
the Godot Asset Library's v1.11 points at) was removed, so the same files are kept here.

The release zip holds `dist/addons/GodotApplePlugins*` exactly as upstream published them, unchanged.
